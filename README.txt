QuizVerse 

An interactive quiz application built using HTML, CSS and JavaScript.

📁 Project Files

- "index.html" – Application structure
- "style.css" – Styling and responsive design
- "script.js" – Quiz logic and functionality

🚀 How to Run

1. Extract the project ZIP.
2. Open the QuizVerse folder in VS Code.
3. Right-click "index.html".
4. Select Open with Live Server.

You can also open "index.html" directly in your browser.

✨ Features

- 6 quiz categories: Python, HTML, CSS, JavaScript, General Knowledge and Aptitude.
- 3 difficulty levels: Easy, Medium and Hard.
- 360 questions in total.
- 20 questions per category and difficulty level.
- 10 randomly selected questions per quiz attempt.
- Randomized answer options.
- 20-second timer per question.
- Progress bar and question navigator.
- Score calculation and answer review.
- XP scoring: 10 XP per correct answer and 50 bonus XP for a perfect score.
- Dashboard with recent attempts, average accuracy and best score.
- Achievements and badges.
- Profile name and streak counter.
- Light and Dark themes.
- Local leaderboard.
- LocalStorage support.
- Responsive user interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

⚠️ Important Limitations

QuizVerse is a frontend-only browser application.

Quiz attempts, profile details, XP, achievements and leaderboard data are stored in LocalStorage on the current browser and device.

There is no real user authentication, cloud database or shared online leaderboard. A backend and database are required for multi-user accounts, cross-device synchronization and a shared leaderboard.
